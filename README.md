An agent-focused docs framework. Let your AI agent write simple .mdx docs using a small set of predefined components, while you read and comment on them in a beautiful docs website, just like any other docs site.

Read more: [mdxctl.micany.com](https://mdxctl.micany.com/)

## Installation

**Install skill (recommended)**

```bash
npx skills add micanyoss/mdxctl
```

Or install it manually:

```bash
npm install -g mdxctl
```

## Usage

**Setup**

```bash
mdxctl init
```

**Start**

```bash
mdxctl start
```

The docs site URL will be printed in your terminal.
